# Security Policy

## Reporting Security Issues

If you discover a security vulnerability or suspicious behavior in:
- Reward model scoring  
- Data pipelines  
- Training scripts  
- Evaluation tools  

Please report it privately to the repository maintainer (Aklesh Mishra).

We will:
- Validate the report within 48 hours  
- Provide a remediation patch  
- Credit the researcher (optional)

## Supported Versions

| Version | Supported |
|---------|-----------|
| v1.0    | ✔ Fully supported |
| < v1.0 | ✘ Deprecated |
